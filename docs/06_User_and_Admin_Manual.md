# CargoPlus 用户与管理员操作手册 (User & Admin Manual)

---

## 1. 系统角色与功能视图

CargoPlus 平台区分两种角色身份：
1. **系统管理员 (System Admin)**：负责全局监控、大模型服务器配置与动态探活、租户准入审核、租户单价与并发上限配置、人工充值以及全局财务对账；
2. **企业租户 (Tenant / Client)**：货代企业用户，拥有独立的对账门户、API Key 密钥管理、邮件抽取实时测试工作台与本企业日账单明细导出。

---

## 2. 货代客户（企业租户）操作指引

### 2.1 自助注册开户与审核
1. 访问注册页面：[http://localhost:8000/register](http://localhost:8000/register)；
2. 填写**企业名称**、**联系邮箱**、**联系电话**及**登录密码**；
3. 点击【立即注册开户】，系统将提示：
   > 开户申请已提交！您的企业租户目前处于【待审核】状态，待管理员审核开通后即可登录使用。
4. 注册成功后系统将预分配 ¥50.00 试用体验金（包含 100 次免费抽取额度）。

---

### 2.2 租户登录与密钥获取
1. 访问登录页面：[http://localhost:8000/login](http://localhost:8000/login)；
2. **登录方式**：
   - 方式一：输入**企业联系邮箱** + **登录密码**；
   - 方式二：直接输入企业 **API Key 凭证**（`cg_...`）免密登录；
3. 登录后自动进入【企业对账中心】（`/portal`）：
   - 顶部提供 **API Key** 与 **Webhook Secret** 实时展示；
   - 点击【复制 API Key】或【复制 Secret】按钮，系统会通过优雅的 Toast 气泡提示“复制成功”，方便直接填入货代 ERP 或客户端脚本中。

---

### 2.3 财务对账中心使用
1. **实时余额与单价**：卡片展示当前账户可用余额、预留金额与当前生效的调用单价；
2. **按日账单汇总 (支持分页)**：
   - 按天展示调用总单数、成功扣费金额与日末余额；
   - 支持通过【上一页】/【下一页】分页翻阅历史账单；
3. **逐笔扣费流水 (支持分页)**：
   - 包含交易编号、关联任务 ID、扣费金额、变动前/后余额及交易时间；
4. **一键导出电子账单**：
   - 点击【导出 CSV 账单】，系统自动下载包含完整期初期末对账信息的 CSV 文件，支持直接在 Excel 中打开核对。

---

### 2.4 邮件抽取实时测试工作台
1. 访问控制台工作台区域；
2. **选择计费租户**：下拉选择本次测试承担扣费的企业租户；
3. **文本抽取模式**：直接粘贴订舱确认邮件中英混排文本，点击【执行 V3 结构化抽取】；
4. **附件上传模式**：拖拽 `.eml` 邮件、`.pdf` 提单、`.xlsx` 箱单或图片附件进行即时解析；
5. **动态模型感知与结果呈现**：
   - 执行中系统动态显示当前正在调用的实际大模型；
   - 抽取完成后右侧动态显示实际调用模型、耗时及 57 个核心字段规范的 JSON 结果，支持一键格式化与复制。

---

## 3. 系统管理员操作指引

### 3.1 管理员登录
1. 访问登录页面：[http://localhost:8000/login](http://localhost:8000/login)；
2. 切换至【管理员登录】标签页，输入用户名 `admin` 与管理员密钥（默认 `cargo-plus-admin-secret-2026`）；
3. 登录后进入【管理员总控大盘】（`/`）。

---

### 3.2 大模型服务配置与 API 动态探测 (LLM Config)
1. 导航进入【LLM 配置】面板；
2. **快捷服务商预设**：
   - 点击顶部快捷预设按钮（如「商汤 SenseAudio」、「DeepSeek 官方」、「硅基流动」、「阿里云百炼」、「智谱 AI」、「OpenAI 官方」、「本地 Ollama」），系统将自动一键填入该服务商的标准 Base URL 和推荐模型；
3. **动态拉取上游 API 模型 (`POST /admin/llm-config/models`)**：
   - 填入对应服务商的 API Key 后，点击模型标识旁边的 **「🔄 从 API 获取模型」** 按钮；
   - 系统将自动探测目标服务商的 `/models` 端点，并将获取到的全部可用模型实时填充至下拉选择菜单中（实测商汤平台可直接拉取 39 个可用模型）；
4. **手动输入自定义模型**：
   - 若使用私有微调或新上线模型，可在下拉菜单中选择 **「✏️ 手动输入其他自定义模型...」**，在弹出的输入框中直接填写模型名称；
5. **连通性测试与测速 (`POST /admin/llm-config/test`)**：
   - 点击 **「⚡ 测试连通性」** 按钮，系统实时向模型发起轻量探测，并在下方绿色/红色面板中反馈往返耗时（如 `1280ms`）与响应预览；
6. **保存与即时生效**：
   - 点击 **「保存并应用配置」**，新配置即刻保存入库并热加载生效，所有后续抽取任务自动切换为新模型。

---

### 3.3 租户准入审核与状态管理
1. 在总控台【租户管理】列表查看所有注册企业；
2. **待审核租户审核**：
   - 新注册企业标签显示为【待审核】（橙色）；
   - 点击操作栏【审核通过】按钮，弹出确认对话框，确认后租户状态变更为【正常】（绿色），租户即刻可以登录调用；
3. **启用/禁用管理**：
   - 对违规或欠费租户可随时点击【禁用】，禁用后租户无法登录且 API 调用返回 `403 Forbidden`。

---

### 3.4 租户人工充值与参数配置
1. **人工充值**：
   - 点击对应租户操作栏的【充值】按钮；
   - 输入充值金额（如 `500.00`）与充值备注；
   - 确认后系统原子增加租户余额并生成 `RECHARGE` 财务流水；
2. **修改调用单价**：
   - 点击【修改单价】按钮，在 ¥0.01 ~ ¥100.00 范围内调整单次计费金额（如 VIP 客户特惠调整为 `¥0.35`）；
3. **调整并发上限**：
   - 点击【并发配置】，在 1 ~ 30 范围内动态调整该租户的最大并发线程限额。

---

### 3.5 任务全流程检索与重试
1. 在【邮件抽取任务流水】中全局查看所有租户的任务处理状态；
2. 对因上游网络超时偶发的 `FAILED` 任务，支持点击【重试任务】重新投递消费；
3. 失败任务重试成功后自动结算扣费，避免遗漏业务单证。

---

## 4. 常见问题解答 (FAQ)

**Q1：新注册租户为什么登录提示“待审核”？**
> 为保障平台商业安全与防止恶意调用，所有新注册租户默认需由管理员在控制台审核激活。请联系系统管理员在后台点击【审核通过】即可。

**Q2：如何快速切换到我自己的本地 Ollama 或自建大模型服务？**
> 1. 登录管理员后台进入【LLM 配置】面板；
> 2. Base URL 填写您的服务地址（如 `http://192.168.1.100:11434/v1`）；
> 3. 点击「🔄 从 API 获取模型」，系统会自动拉取本地 Ollama 部署的模型；
> 4. 点击「⚡ 测试连通性」验证成功后，点击「保存并应用配置」即可。

**Q3：任务抽取失败会扣费吗？**
> 绝对不会。系统采用原子预留与成功结算机制。只有任务状态为 `SUCCESS` 并通过 57 字段格式校验时才会扣费；任何失败、超时或异常终止的任务，费用均为 ¥0.00，预留金额自动全额释放。

**Q4：API 调用报 HTTP 429 怎么处理？**
> 说明当前租户的并发请求数超过了配置上限（默认 20 并发）。系统会在响应头中返回 `Retry-After: 3`，客户端只需在 1~3 秒后自动重试即可，任务不会丢失。
