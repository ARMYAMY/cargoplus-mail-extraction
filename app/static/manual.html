CargoPlus 用户手册与集成指引

CargoPlus 采用现代工业级 Skill V3 架构，为国际货运代理、无船承运人（NVOCC）及物流 ERP 系统提供高并发、高精度的邮件与附件单证结构化抽取服务。

1. 快速接入指南

仅需三步即可完成生产环境对接：

  1. 注册开户：访问 企业开户页面 提交申请，获取唯一的 API Key 与 Webhook Secret；
  2. 提交抽取：向 /api/v1/extract/async 或 /api/v1/extract/async/upload 提交订舱确认邮件正文或多模态附件（支持 .eml, .pdf, .xlsx, .docx, .doc, 扫描图片 等全格式单证）；
  3. 接收通知：配置回调地址 callback_url，抽取成功后系统将自动以 HMAC-SHA256 签名方式将 57 个标准结构化字段推送到您的业务系统。

2. 认证鉴权规范

所有客户端调用需在 HTTP 请求头中携带企业 API Key：

Authorization: Bearer cg_live_xxxxxxxx_yyyyyyyyyyyyyyyyyyyyyyyy

或通过自定义 Header 传入：

X-API-Key: cg_live_xxxxxxxx_yyyyyyyyyyyyyyyyyyyyyyyy

3. 异步邮件抽取接口 (POST /api/v1/extract/async)

适用于生产环境 ERP 对接。系统执行原子额度预留并进入削峰队列处理。

请求体 JSON 参数：

字段名类型必填说明
mail_subjectstring否邮件标题
mail_bodystring是邮件正文内容（中英混排）
callback_urlstring否抽取完成后的 Webhook 接收地址

Python 示例代码：

import requests

url = "http://localhost:8000/api/v1/extract/async"
headers = {
    "Authorization": "Bearer cg_live_your_api_key",
    "Content-Type": "application/json",
    "Idempotency-Key": "req_unique_id_12345"  # 防重复提交幂等键
}
payload = {
    "mail_subject": "Booking Confirmation - 2x40HQ SHANGHAI TO ROTTERDAM",
    "mail_body": "DEAR CUSTOMER, BOOKING NO: COSU638291048, VESSEL: CSCL GLOBE / 042W, POL: SHANGHAI, POD: ROTTERDAM",
    "callback_url": "https://your-erp.com/webhooks/cargo"
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())

4. 同步即时抽取接口 (POST /api/v1/extract/sync)

客户端阻塞等待抽取完成并直接返回 57 字段规范 JSON（包含实际生效的模型 model_used 与耗时 duration_ms）。

5. 任务状态与结果查询 (GET /api/v1/tasks/{task_id})

若未使用 Webhook，客户端可轮询查询任务的实时状态与抽取详情。

6. Webhook 签名校验规范 (HMAC-SHA256)

为防止重放攻击与伪造通知，系统在推送结果时会附带签名 Header：

X-Timestamp: 1724064600000
X-Signature-SHA256: d5a4e6b2c86472...

Python 验签函数：

import hmac
import hashlib
import time

def verify_webhook(raw_body_bytes: bytes, timestamp_str: str, signature_header: str, tenant_secret: str) -> bool:
    # 1. 防重放攻击 (偏差不超过 5 分钟)
    if abs(int(time.time() * 1000) - int(timestamp_str)) > 300_000:
        return False
    # 2. 计算签名: HMAC_SHA256(secret, timestamp + "." + body)
    message = f"{timestamp_str}.".encode("utf-8") + raw_body_bytes
    expected_sig = hmac.new(tenant_secret.encode("utf-8"), message, hashlib.sha256).hexdigest()
    # 3. 恒定时间比对
    return hmac.compare_digest(expected_sig, signature_header)

7. V3 57 核心字段规范概览

系统自动识别并归一化海运订舱核心要素：

  • 订舱与船期：BookingNo, Carrier, Vessel, Voyage, SO, ETD, ETA, ClosingDate, CutOffDate 等；
  • 港口代码：POL (五字码如 CNSHA), POLName, POD (如 NLRTM), PODName, TransitPort；
  • 集装箱与箱型：ContainerInfo (数组包含 ContainerNo, ContSize: 20/40/45, ContType: GP/HQ/NOR/RF, SealNo)；
  • 件重体分离：Packages, PackagesUnit, GrossWeight, GrossWeightUnit, Volume, VolumeUnit；
  • 收发通实体：Shipper, ShipperAddr, Consignee, ConsigneeAddr, NotifyParty, NotifyPartyAddr；
  • 品名拆分：GoodsName (英文品名), GoodsNameCN (中文品名)。

8. 常见响应状态码与错误处理

HTTP 状态码错误场景解决指引
200 OK请求成功正常获取任务 ID 或抽取结果
401 UnauthorizedAPI Key 无效或未提供检查请求头中的 Authorization: Bearer <key>
402 Payment Required账户可用余额不足请联系管理员为企业充值或充值后重试
403 Forbidden租户处于待审核或已禁用待管理员在控制台审核激活后即可调用
429 Too Many Requests超出并发限制系统已返回 Retry-After，建议 1~3 秒后自动重试
